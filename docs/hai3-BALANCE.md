# 灰の王 III ── 武器バランス調査（build 3e）

## 方法

- ゲーム内の実際の式（`atkMult` / `magMult` / `prayMult`、軟上限つき能力値、強化倍率、敵の相性表 `RES`/`KRES`）をブラウザ上で評価し、その値を使って解析モデルで比較した（`/home/claude/test3/b1.py`・`b2.py`・`b3.py`）。
- 基準ビルド：**Lv20/+5**、**Lv35/+8**、**Lv50/+10**（特別な武器は +2/+4/+5）。能力値は必要能力を満たしたうえで、ポイントの4割を体力・持久力、残り6割を「その武器の攻撃力が最も伸びる能力」へ1点ずつ貪欲に配分。
- 戦闘モデル：強敵は 3.4 秒ごとに 1.7 秒の「攻撃できる隙」を見せると仮定（精鋭は 2.6 秒ごと）。隙の中で、軽攻撃の連撃／強攻撃→連撃／連撃→強攻撃／（大剣）溜め斬り のうち最もダメージが出る組み合わせを選ぶ。体勢値が溜まれば致命の一撃（強攻撃×2.3×致命倍率）、出血は蓄積100で発動（強敵は60×出血倍率、以後12%ずつ重くなる）。
- 武器種ごとの固有の技は平均的な稼働率で織り込んだ：剣の調子 +14%、盾なし片手剣の振り +12%、居合（隙の初撃 +50%）、連舞・狂乱（振り +15%）、穿孔（5発目 +50%・体勢+45）、間合い +12.5%、旋回・穂先 +10%、猛り +7.5%、刈り取り（出血 +30%）、背撃（雑魚のみ +25%）、溜め斬り（+0.9秒で +55%）。
- TTK（撃破までの秒数）の対象：**灰冠の騎士王**（HP 1000・体勢 110）、**第2層の主 灰燼の大主教**（HP 3600）、**精鋭の鎧騎士**（HP×1.6）。いずれも相性倍率込み。
- モデルの限界：被弾・空振り・位置取りは入っていない。遅い武器ほど実戦では数字より不利、盾・槍・弓・魔法は数字より安全、という補正は人の判断で加えた（下の「調整方針」）。
