# 灰の王 III — 層の設計メモ (layer / level / boss roadmap)

## 構造
- 世界は **層 (layer)** の列。各層は「手作りのマップ + 祝福 + 近道 + 敵 + 中ボス + 層の主」で一つ。
- 層の主を斃すと次の層への **昇降機 (`lift` prop)** が動く。祝福は層をまたいで **転移** できる。
- 地下墓（生成ダンジョン）と「灰の降る夜」は第1層に属する寄り道。隠しボスは地下墓 B7。

|---|---|---|---|---|
| 1 | 灰の城 | 灰冠の騎士王 ヴァルグレイ（専用アリーナ・2形態） | Lv15–20 | 実装済み |

## レベル曲線
- n 回目のレベルアップ費用: `cost(n) = 90 + 38n + 2.6n²`（n = 現在レベル − 1）。`a.js` の `lvCost()`。
  - Lv11: 730 / Lv21: 1,890 / Lv31: 3,570 / Lv41: 5,770 / Lv51: 8,490
  - 累計: Lv20 ≈ 14k / Lv30 ≈ 38k / Lv40 ≈ 78k / Lv50 ≈ 148k
- 旧式 (`90·1.12ⁿ + 30n`) は Lv20 まではほぼ同額、Lv30 以降が急壁だった。新式は二次式で壁がない。
- ルーン収入の目安: 第1層 一周 ≈ 2.5k + 中ボス 4.3k + 王 3k、夜は 1.5 倍、地下墓は階ごとに +35%。
  第2層: 雑魚 150–420、中ボス 4,500 ×3、主 15,000（一周 ≈ 7k + ボス 28.5k → Lv20→30 に必要な 24k を賄える）。
  第3層以降は雑魚 400–900、主 30k 以上を目安にすれば Lv50 まで「長いが止まらない」。
- 能力のソフトキャップ（`a.js` の `eff / hpOf / stOf / fpOf / capOf`）:
  - 体力: +12/pt（〜30）→ +7（〜50）→ +3
  - 持久力: スタミナ +8 と重量上限 +1.5（〜25）→ +4 / +0.8
  - 筋力・技量・知力・信仰: 実効値 = 素の値（〜30）→ 以降は半分（〜50）→ 2割
  - 知力の FP: +5（〜30）→ +2.5

## 相性（ダメージ属性）
- 属性: 斬撃 slash / 打撃 strike / 刺突 pierce / 魔力 magic / 聖 holy / 炎 fire、別枠で出血の溜まりやすさ。
- 武器ごとに `dt`（突き攻撃は自動で刺突）。敵は `RES[type]`（`c.js`）に倍率（弱点 1.1–1.4、耐性 0.6–0.9）。
- 完全無効は作らない: **どのボスもどの武器でも倒せる**（最悪でも 0.6 倍）。出血だけは石像系で 0.15。
- 王の相性は `KRES`。図鑑は倒した敵の相性を表示。

## 層を足す手順（第3層以降）
1. `b.js` に `L2DEF` と同じ形の定義を書く（`lay`, `base`=10×(lay−1), `rooms`, `pillars`, `torches`, `bless`, `chests`, `doors`, `spawns`, `carpets`, `props`, `dm`, `bossDm`）。
2. `LAYERS` に `{ lay, base, name, level, open }` を足す（`open` は前の層の主の討伐フラグ `save.lords[lay-1]`）。
3. 敵は `EDEF` に追加。既存の AI/見た目を `ai` / `look` / `sc` で流用できる。相性は `RES`。
4. 中ボス・主は `MBAI[type]` に `ai` と技の関数を書く（既存の技関数を呼び出して組み合わせても良い）。主は `lord: 1`、2形態は `shift` 技。
5. 前の層に `lift` prop（`to` = 新しい層の最初の祝福 id）、新しい層に戻りの `lift` と主の部屋への `fogL` を置く。
6. 宝箱 id・扉 id は層ごとに接頭辞を変える（`q*`, `L2d*`）。ドロップは `MBDROP`。BGM は `TRK` に足して `pickTrack()` で選ぶ。

## 武器
- 17 種類 × 約 3 本 = 51 本（+ 素手）。`mkW()` で種類の基準武器から派生させる。各武器は `BOUND` に固有戦技を持つ。
- 第2層以降でしか手に入らない武器が 22 本。層を足すたびに 5–8 本ずつ足す想定。
