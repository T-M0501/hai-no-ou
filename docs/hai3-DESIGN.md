# 灰の王 III — 層の設計メモ (layer / level / boss roadmap)

## 構造
- 世界は **層 (layer)** の列。各層は「手作りのマップ + 祝福 + 近道 + 敵 + 中ボス + 層の主」で一つ。
- 層の主を斃すと次の層への **昇降機 (`lift` prop)** が動く。祝福は層をまたいで **転移** できる。
- 地下墓（生成ダンジョン）と「灰の降る夜」は第1層に属する寄り道。隠しボスは地下墓 B7。

## レベル曲線
- n 回目のレベルアップ費用: `cost(n) = 90 + 38n + 2.6n²`（n = 現在レベル − 1）。`a.js` の `lvCost()`。
  - Lv11: 730 / Lv21: 1,890 / Lv31: 3,570 / Lv41: 5,770 / Lv51: 8,490
  - 累計: Lv20 ≈ 14k / Lv30 ≈ 38k / Lv40 ≈ 78k / Lv50 ≈ 148k
- 旧式 (`90·1.12ⁿ + 30n`) は Lv20 まではほぼ同額、Lv30 以降が急壁だった。新式は二次式で壁がない。
- ルーン収入の目安: 第1層 一周 ≈ 2.5k + 中ボス 4.3k + 王 3k、夜は 1.5 倍、地下墓は階ごとに +35%。
  第2層: 雑魚 150–420、中ボス 4,500 ×3、主 15,000（一周 ≈ 7k + ボス 28.5k → Lv20→30 に必要な 24k を賄える）。
  第3層以降は雑魚 400–900、主 30k 以上を目安にすれば Lv50 まで「長いが止まらない」。
- 能力のソフトキャップ（`a.js` の `eff / hpOf / stOf / fpOf / capOf`）:
  - 体力: +12/pt（〜30）→ +7（〜50）→ +3
  - 持久力: スタミナ +8 と重量上限 +1.5（〜25）→ +4 / +0.8
  - 筋力・技量・知力・信仰: 実効値 = 素の値（〜30）→ 以降は半分（〜50）→ 2割
  - 知力の FP: +5（〜30）→ +2.5

## 相性（ダメージ属性）
- 属性: 斬撃 slash / 打撃 strike / 刺突 pierce / 魔力 magic / 聖 holy / 炎 fire、別枠で出血の溜まりやすさ。
- 武器ごとに `dt`（突き攻撃は自動で刺突）。敵は `RES[type]`（`c.js`）に倍率（弱点 1.1–1.4、耐性 0.6–0.9）。
- 完全無効は作らない: **どのボスもどの武器でも倒せる**（最悪でも 0.6 倍）。出血だけは石像系で 0.15。
- 王の相性は `KRES`。3e から図鑑には相性を載せない（戦闘中のダメージ数字の色と「弱点」「耐性」表示で気づかせる）。

## 層を足す手順（第3層以降）
1. `b.js` に `L2DEF` と同じ形の定義を書く（`lay`, `base`=10×(lay−1), `rooms`, `pillars`, `torches`, `bless`, `chests`, `doors`, `spawns`, `carpets`, `props`, `dm`, `bossDm`）。
2. `LAYERS` に `{ lay, base, name, level, open }` を足す（`open` は前の層の主の討伐フラグ `save.lords[lay-1]`）。
3. 敵は `EDEF` に追加。既存の AI/見た目を `ai` / `look` / `sc` で流用できる。相性は `RES`。
4. 中ボス・主は `MBAI[type]` に `ai` と技の関数を書く（既存の技関数を呼び出して組み合わせても良い）。主は `lord: 1`、2形態は `shift` 技。
5. 前の層に `lift` prop（`to` = 新しい層の最初の祝福 id）、新しい層に戻りの `lift` と主の部屋への `fogL` を置く。
6. 宝箱 id・扉 id は層ごとに接頭辞を変える（`q*`, `L2d*`）。ドロップは `MBDROP`。BGM は `TRK` に足して `pickTrack()` で選ぶ。

## 武器
- 17 種類 × 約 3 本 = 51 本（+ 素手）。`mkW()` で種類の基準武器から派生させる。各武器は `BOUND` に固有戦技を持つ。
- 第2層以降でしか手に入らない武器が 22 本。層を足すたびに 5–8 本ずつ足す想定。

## 3e: 手・盾・固有の技・タリスマンの品・メニュー
ソースは `/home/claude/build3e/`（`build.py` が `head.html a b c d e f x w g` を結合）。新しいロジックは主に `w.js`。

### 右手と左手
- `save.weapon`（右手）＋ `save.off`（左手：盾 id / 片手武器 id / 触媒 id / null）。`WPN[k].two` が両手専用（大剣・特大剣・斧槍・鎌・爪・弓・素手）。
- `offId()` / `offKind()` → `'shield' | 'dual' | 'cat' | null`。重量は `offWt()` を `calcLoad` に加算。
- 盾は `SHD`（`a.js`）：`type` 小盾/中盾/大盾、`cut` カット率、`stab` 受け（小さいほど堅い）、`el` 魔・炎・衝撃波に対するカット率の係数、`pry` パリィ窓（大盾は null）、`fx`（`fp`＝パリィでFP、`thorn`＝棘返し）。
- ガードは状態 `guard`（`e.js`）、被弾処理は `guardHit()`（`w.js`）。正面 ±1.9rad。足元の炎など `light && !src && !proj` はガード不可。スタミナ 0 で「ガード崩し」。
- パリィは従来の `parry` 状態を盾の `pry` で使う。押し続けていれば `P.gHold` でガードへ移行。
- 6 個目のボタン `btns[5]`（k: 'guard'、キー F）。`guardBtnOn()` が真のときだけ表示・当たり判定。配置エディタの `EDK` に入っている。
- 二刀流：`startLight(i)` が右・左を交互に（`P.wid` が左手武器 id）。強攻撃は `P.dual2` で左の追撃（双撃）。同種 +5%。
- 旧「盾と片手剣」3 本は片手剣（`cls: '片手剣'`）になり、`sanitize()` が `save.hands` 未設定のセーブに対応する盾（kite / round2 / tower2）を配って同じ構成で持たせる。開封済み宝箱に後から足した盾・魔法も同じ箇所で配る。

### 魔法剣士（素性ではなく持ち方）
- 右手に近接武器＋左手に杖か聖印 → `offKind() === 'cat'`。ガードボタンが「詠唱」になり `spellList()` の現在の項目を唱える。
- 先頭は必ず `enc`（刃の纏い・`ENC`）：杖なら魔力、聖印なら聖を 35 秒。`setEnch(el, t, k)`、残りは `P.enchT`、倍率 `P.enchK`（触媒の `magMult`/`prayMult`）。
- 纏い中：命中ごとに `enchHit()`（基礎ダメージ×25%×enchK、属性相性あり）、強攻撃と連撃の締めで `enchWave()`（斬撃波 16/24×enchK）。
- 魔法 `e_magic` / `e_fire` / `e_holy` は強い版（45 秒・1.25 倍）。炎は `e_fire` のみ。戦技ベース `chant`（聖灯の剣）も `setEnch` を使う。
- 知力/信仰で伸びる剣：`msword`（第1層 c16）、`msword2`・`hsword`（第2層）。

### 武器種ごとの固有の技
- 説明は `WMECH`、処理は `w.js` の `mechStart / mechMul / mechSpd / mechAfter / mechHurt / mechTick`、HUD は `mechInfo()`（武器名の下の小ゲージ）。
- 命中ごとの判定（背撃・間合い・穿孔・粉砕・旋回・刈り取り）は `playerStrike()` の 2 パス目。溜め斬りは `holdCharge()`、詠唱溜めは `cast` 状態、弓は `fireArrow()` の矢種（`P.arrowT`）と `snipe`。
- どの技もボス撃破に必須ではない（倍率は +6〜+60% の上乗せのみ）。新しい武器種を足すときは `WMECH` に 1 行と、上の関数のどれかに分岐を足す。

### タリスマン
- 枠は 2 → 最大 4。護符の紐は第1層に 2 本（宝箱 c18、鎧騎士の初回撃破）。既存セーブは `sanitize()` で `2 + c18 + 鎧騎士` を下回らないよう補正。
- 品 `save.trar[id]` = 1〜4（`RAR`）。効果は `tk(id)`（未装備 0、装備中は品の係数 1 / 1.25 / 1.55 / 1.9）を各式に掛ける。★3 以上は `secDef()` で被害 −2% / −4%。
- 入手：宝箱・強敵の `{ t, r }`、`dropTal()`（精鋭・第2層・地下墓の深い階・夜）。上の品は昇格、同じか下はルーン（250×r²）。
- 層を足すときは、その層の宝箱に ★3、主に ★4 を 1 つ置くのを目安にする。

### メニュー構成
- 祝福：休息／レベルアップ（振り直しはこの中）／強化／転移／地下墓へ（開いているときだけ）／祝福から離れる／メニュー。
